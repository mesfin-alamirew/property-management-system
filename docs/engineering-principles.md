Principle 1

Business logic lives in the feature.

Principle 2

Reusable code lives in shared components.

Principle 3

Don't duplicate working code.

Principle 4

Abstract only after a pattern is proven.

(We've followed this throughout the Form Library.)

Principle 5

Behavior before structure.

Never break working business logic just to improve code organization.

Principle 6

Small, verifiable refactoring.

Never rewrite an entire feature unless absolutely necessary.

Principle 7

Every module should look familiar.

When someone opens:

Country
Region
Property
Tenant
Owner

they should immediately recognize the structure.
